## [Day 1] 2026-07-21

- 핵심 안건: 30일 단기 C++ 콘솔 프로젝트 방향성 및 코어 시스템 확립
- 주요 결정 사항:
  1. 프로젝트 룰 확립
     - 기간 내 완성 가능한 현실적인 스코프 유지.
     - 자료구조, 객체지향 등 C++ 클라이언트 프로그래밍 역량 강화에 초점.
     - AI(기획 논의 상대)는 철저히 '기획'만 담당하며, 개발은 별도 진행.
  2. 게임 장르 및 환경
     - 장르: 로그라이크 턴제 전투 게임.
     - 환경: 순수 C++ 및 Windows Console API 활용 (화면 깜빡임 방지).
  3. 맵 구조 (Map Structure)
     - 그래프(Graph) 자료구조 기반의 '노드(Node) 선택 탐색형' 맵.
     - 총 5개의 Map(층/Round)으로 구성.
     - 그리드(Grid) 타일 이동 방식은 개발 및 렌더링 리소스 문제로 배제함.
  4. 코어 메커니즘: 정보 해금과 자원 관리
     - 제한 요소 (자원): '수면 심도(Sleep Depth)'
       - 내러티브: 주인공이 꿈속에서 기억의 파편을 찾는 과정. 수면 심도가 0이 되면 꿈에서 깨어나며 게임 오버(Run 실패).
       - 소모: 노드 간 이동 시 소모, 미지의 노드를 '정찰(Scout)'하여 정보를 해금할 때 더 큰 수치 소모.
  5. 노드의 종류 (Rooms)
     - 휴식처: 수면 심도 또는 HP 1회성 회복.
     - 전투방: 일반 몬스터 전투 및 보상 획득.
     - 상인의 방: 재화 소모 및 즉시 적용 가능한 스탯/소모품 구매 (복잡한 인벤토리/장비 시스템 배제).
     - 잠긴 문: 다음 층(Map)으로 넘어가기 위한 출구 (특정 조건/열쇠 필요).
- 다음 논의 예정 사항 (Pending):
  - '잠긴 문'을 열기 위한 열쇠(기억의 파편 등) 획득 방식 결정.

## [Day 2] 2026-07-22

- 핵심 안건: 마스터 GDD 구체화 — 스탯 체계, 맵 테마, 신규 코어 시스템(꿈조합) 확정
- 주요 결정 사항:
  1. 플레이어 스탯 확정
     - HP, ATK(공격력), DEF(방어력) 도입. 전투는 속도(Speed) 계산 없이 플레이어-적 1:1 교대 턴.
     - 인벤토리: 장착 무기 슬롯 1개 + 주머니 슬롯 3개로 규모 확정 (복잡한 장비 시스템 배제 기조 유지).
  2. 열쇠 획득 방식 확정 (Day 1 pending 해결)
     - 노드에 '엘리트 전투방(EliteNode)' 추가 — 중간 보스전이며 승리 시 '기억의 파편'(열쇠) 확정 드롭.
  3. 맵 테마 확정 — 5개 Map을 감정 테마(향수/우울/분노/공포/공허)로 차별화하고, 층마다 시스템적 페널티(수면 심도 소모량, 적 강도, 휴식처 빈도 등) 부여.
  4. 신규 코어 시스템: 꿈조합(Dream Synthesis)
     - 일상 도구 2개를 조합해 '꿈무기'로 재창조하는 시스템. 탐색 중(ExplorationState)에만 가능, 전투 중 불가.
     - 구현 방향: `enum class` + 비트마스크로 아이템 속성 관리, 팩토리 패턴 + `std::move`로 조합 시 기존 객체 해제/신규 객체 반환.
  5. 포트폴리오 어필 포인트 추가 확정
     - 메모리 최적화(Object Pool, capacity 제어), `std::move` 기반 소유권 이전, 비트마스크/구조체 패딩 최적화.
  6. 문서 정리: Day 2 내용 정리 중 '상인의 방' 노드가 목록에서 누락되어 있었음을 확인 — 삭제된 것이 아니라 여전히 유효한 노드로 재확인함 (`docs/game_design.md` 4절에 복원).
- 다음 논의 예정 사항 (Pending):
  - 전투 시스템 상세 로직 (스킬/방어/회피 등)
  - 몬스터·보스(엘리트 포함) 종류와 패턴
  - 상인의 방 재화/물가 밸런싱
  - 꿈조합 아이템 테이블 (Base/Modifier 상세 목록)

## [Day 3] 2026-07-26

- 핵심 안건: 통합 마스터 기획 명세서로 세부사항 구체화 — 전투 시스템, 상점 시스템 신규 확정
- 주요 결정 사항:
  1. 플레이어 스탯 세부 규칙 확정
     - 수면 심도 최대치는 층 클리어마다 영구 확장.
     - 맨몸 기준 ATK 1 / DEF 0 고정, 스탯 성장은 오직 장착 무기를 통해서만 이루어짐 (별도 레벨업 없음).
     - 주머니 3슬롯이 가득 차면 추가 재료 획득 불가 (예외 처리 규칙 명시).
  2. 휴식처(RestNode) 규칙 구체화
     - `[휴식: HP 30% 회복]` 또는 `[단련: Max HP +5]` 중 하나만 선택 가능하도록 확정 (기존엔 회복만 있었음).
  3. 엘리트 전투방(EliteNode) 보상 확정
     - 열쇠(기억의 파편) 획득 외에 Max HP +20 영구 성장 + 현재 HP 완충 추가.
  4. 전투 시스템 상세 로직 확정 (Day 2 pending 해결)
     - 1:1 교대 턴제. 플레이어 행동: 공격(장착 무기 데미지) / 도구 사용(주머니 소모, 즉발 효과) / 방어(피해 감소).
  5. 상점(MerchantNode) 시스템 신규 확정 (Day 2 pending 일부 해결)
     - 재화명 확정: '무의식의 잔재' (일반/엘리트 전투 승리로 획득).
     - 판매 품목: 심연의 물약(즉시 Max HP+10 및 회복, 인벤토리 비경유) / 무작위 조합 재료(현재 맵 테마 기반, 주머니 슬롯 소모).
     - 구매 횟수 제한 없음, 재화 부족·주머니 가득 참 시에만 제한. 퇴장 시 빈 방으로 전환.
     - 물가(구체적 가격 수치)는 아직 미정으로 남음.
  6. 꿈조합 로직 구체화
     - Base 1개 + Modifier 1개 = 새 무기 1개 생성이라는 조합 비율 확정 (기존엔 "도구 2개 결합"이라고만 되어 있었음).

## [Day 3 추가 정정] 2026-07-26

- `RestArea` 구현 중 문서와 실제 기획 의도가 어긋난 부분을 발견해 정정함.
  - 휴식처는 원래도 세 선택지(수면 심도 회복 / 체력 회복 / 단련: 최대 체력 증가)로 기획되어 있었으나, `game_design.md` 9절엔 두 가지(휴식/단련)만 반영되어 있었음 — 문서 누락으로 확인, 세 선택지로 정정.
  - 체력 회복 방식은 정액 회복 vs 현재 HP 비율(%) 회복 중 아직 결정 전 — 미정으로 명시.
  - 각 선택지의 구체적 수치(회복량, 증가량)는 추후 밸런스 조정 대상이므로 문서에서 확정 수치 표기를 제거하고 미정으로 남김.

## [Day 3 V2.0] 2026-07-26 — JRPG 시스템 변환 적용

- 핵심 안건: 통합 마스터 기획 명세서 V2.0 — 장르 재정의, 사망(루프) 시스템, 맵 구조 확정, 신규 노드 타입 추가
- 주요 결정 사항:
  1. 장르 재정의: "턴제 로그라이크" → **"JRPG 스타일 턴제 어드벤처"**로 변경.
  2. 세이브 및 사망 패널티 시스템 신규 확정 (영구 죽음이 아닌 '루프' 방식)
     - 층 진입 시 자동 저장. HP/수면 심도 0 이하 시 사망 → 해당 층 입구에서 부활, 현재 HP/수면 심도 100% 회복, Max 스탯 성장은 유지.
     - 페널티: 주머니 속 꿈조합 재료 중 무작위 절반 유실 (장착 무기는 유지).
  3. 맵 구조 확정: **고정 구조(Fixed Map)** — 절차적/랜덤 생성 배제, 모든 층의 노드 배치는 기획 고정 데이터로 결정.
  4. 신규 노드 타입 추가: **이벤트 방 (EventNode)** — 층의 서사(과거/기억)를 전달, 완료 시 해당 층의 스토리 완료 플래그 활성화.
  5. 잠긴 문(LockedNode) 통과 조건 변경: 기존엔 '기억의 파편' 소지만 확인했으나, **'기억의 파편' 소지 + 해당 층 스토리 완료 플래그 활성화** 두 조건을 모두 요구하도록 강화 (EventNode와 연동).
  6. 전투 시스템에 몬스터 공통 룰 명시: 모든 적은 HP/ATK/DEF/드롭 재화량과 매 턴 행동 패턴을 가짐.
  7. TBD 범위 좁히기: 이후 기획은 **Map 1(향수)로 스코프를 한정**해서 서사/몬스터/아이템을 먼저 확정하고, Map 2~5는 Map 1 구현 후 순차 진행하기로 함. 기존에 남아있던 휴식처 회복 방식·상인의 방 물가 TBD도 이 Map 1 범위 확정 작업에 포함시키기로 함 (별도 항목으로 무기한 유예되는 게 아님).

## [Day 3 V4.1] 2026-07-26 — 수면 심도 시스템 전면 개편, 몬스터 AI/속성 시스템 추가

- 핵심 안건: 수면 심도를 단순 소모 자원에서 양방향 텐션 게이지로 전환, 전투/몬스터 시스템 및 속성 시스템 신규 확정
- 주요 결정 사항:
  1. **수면 심도 시스템 전면 개편** (기존 V2.0의 "HP 또는 수면심도 0 → 동일 패널티" 방식 폐기)
     - 0~100 게이지로 재정의 (시작값 50). 이동/정찰/특정 피격 시 감소, 휴식처의 '수면 심도 회복' 선택 시 증가.
     - **조건 A (0 도달, 강제 기상)**: 층 탐색 실패, 층 입구에서 재시작, **해당 층에서 얻은 아이템 전부 삭제** (이전 층 진행/성장치는 유지).
     - **조건 B (100 도달, 과수면/심연 진입, 신규)**: 하드모드 돌입 — 게이지 100 고정, 맵의 모든 적 강화. 특수 아이템 사용 또는 해당 층 보스 처치+층 이동으로 해제.
     - **조건 C (HP 0, 전투 불능)**: 층 입구가 아니라 **마지막으로 방문한 휴식처에서 부활**, 부활 시 수면 심도 소량 감소 페널티 (수치 TBD). 기존 V2.0의 "재료 절반 유실" 페널티는 조건 C에는 적용 안 됨 (조건 A의 "층 아이템 전부 삭제"로 대체됨).
  2. 재화 명칭 변경: '무의식의 잔재' → **'꿈의 파편'**으로 통일 (CombatNode 드롭, 상점 재화 모두 반영). 코드 쪽의 `Monster::DropTable.DreamFragments` 필드명이 이 변경으로 오히려 기획 용어와 일치하게 됨.
  3. 엘리트 전투방(EliteNode) 보상: 기존 확정이었던 "Max HP+20/현재 HP 완충"이 이번 문서에서 **미정으로 되돌아감** — 재검토 중인 것으로 보임, 재확정 필요.
  4. 전투 시스템에 턴 3단계(Phase) 구조 추가: `상태이상/디버프 정산` → `행동 결정 및 실행` → `턴 종료`.
  5. 몬스터 AI 우선순위 규약 공식화: 1순위(조건부 특수 행동, 예: 자기 HP 30% 이하 시 인터럽트) → 2순위(고정 사이클 반복). 코드에서 이미 이 구조로 `Monster`/구체 몬스터 클래스를 설계 중이었음 — 문서가 진행 중이던 코드 설계를 뒤따라 공식화한 형태.
  6. **감정 속성(Attribute) 시스템 신규 추가**: `[자각/몽환/망각]` 3속성. 상성·효과·부여 룰은 전부 미정.
  7. **Map 1 몬스터 로스터 등장**: `[포근한 뱀 인형]`(망각 속성), `[거짓말을 하는 그림일기]`(몽환 속성) — 기믹은 둘 다 미정.
- ⚠️ **확인 필요 — 몬스터 개명**: 직전에 상세 스탯(HP10/ATK2/DEF0)과 AI 패턴("발악기"/"고장남" 등)까지 설계했던 "먼지 덮인 장난감 병정"이 이번 로스터에 없음. 사용자 확인 결과 "포근한 뱀 인형"으로 개명/교체된 것— 다만 기존에 설계한 상세 스탯·패턴을 그대로 이 몬스터에 이어갈지, 속성(망각)에 맞게 다시 설계할지는 아직 결정 안 됨. `Monster.h` 코드 작업 시 참고.
