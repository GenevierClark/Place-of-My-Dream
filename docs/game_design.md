## 1. 프로젝트 개요

- 프로젝트명: Place of My Dream (POMD)
- 장르: 턴제 로그라이크 (노드 탐색형)
- 플랫폼: C++ 콘솔 환경 (Windows Console API 기반 렌더링)
- 개발 기간: 30일 (여름 집중 포트폴리오 프로젝트)
- 핵심 내러티브: 플레이어는 자각몽 속 무의식의 세계를 탐험하며 잊혀진 '기억의 파편'을 찾아 더 깊은 심연으로 나아간다. 꿈에서 깨어나기 전에 최종 목적지에 도달해야 한다.

## 2. 개발 및 설계 목표 (포트폴리오 어필 포인트)

- 메모리 최적화: `std::vector`의 capacity 제어 및 연속된 메모리 할당(Object Pool)을 통한 캐시 적중률(Data Locality) 향상.
- 모던 C++ 활용: `std::move`를 활용한 R-value 소유권 이전과 팩토리 패턴을 결합하여, 메모리 누수(Leak) 없는 생명 주기 제어.
- 데이터 구조 최적화: 비트마스크(Bitmask) 연산을 통한 상태/속성 제어 및 구조체 메모리 패딩(Padding)/정렬(Alignment) 최적화.
- 객체지향 설계: 다형성을 활용한 유연한 노드(방) 및 엔티티(몬스터, 플레이어) 클래스 구조 설계.
- 자료구조 활용: 노드 간의 연결 상태를 구현하기 위한 그래프(Graph) 활용.
- 상태 관리: 턴제 전투 흐름 및 맵 탐색 씬(Scene) 전환의 State Machine 기반 제어.
- 데이터 캡슐화: 핵심 데이터를 캡슐화하고 이벤트에 유기적으로 반응하는 구조(옵저버 패턴) 구현.

## 3. 플레이어 캐릭터 시스템

### 3.1. 기본 스탯 및 자원

- 수면 심도 (Sleep Depth): 게임의 핵심 자원. 맵 이동, 정찰(Scout), 특수 행동 시 소모. 0이 되면 게임 오버(Run 실패). **매 층(Map) 클리어 시 최대치가 영구적으로 확장됨.**
- 체력 (HP): 전투 패배/피격 시 감소, 0이 되면 게임 오버. 휴식처의 '단련' 선택지나 엘리트 몬스터 처치로 최대 체력(Max HP)을 영구 성장 가능.
- 공격력(ATK) / 방어력(DEF): **플레이어 맨몸 기본 ATK는 1, DEF는 0으로 고정.** 스탯 성장은 오직 장착 중인 무기를 통해서만 이루어짐 (레벨업 등 별도 성장 없음).

### 3.2. 인벤토리 구조

- 장착 무기 슬롯: 1개 (현재 전투에서 사용하는 주력 무기)
- 주머니 슬롯: 3개 고정 (탐색 중 획득한 재료 보관)
- 예외 처리: 주머니가 3칸 모두 찬 상태에서는 추가 재료 획득 제한.

## 4. 맵 및 탐색 시스템 (Map & Exploration)

- 맵 구조: 각 층(Map)은 노드(Node)들이 유기적으로 연결된 그래프(Graph) 구조이며, 뒤로가기가 가능한 탐색형 맵.
- 정보 해금 (Fog of War):
  - 초기 진입 시 인접한 방의 존재는 확인 가능하나, 내부 정보는 `[ ? ]`로 가려짐.
  - 이동(Move): 소량의 수면 심도를 소모하며 인접 방으로 진입 (리스크 감수).
  - 정찰(Scout): 대량의 수면 심도를 소모하여 인접 방의 상세 정보를 미리 해금 (안전 확보).

### 노드(방)의 종류

1. **휴식처 (RestNode)**: 진입 시 아래 세 선택지 중 **단 하나만** 선택 가능. 선택 후 빈 방으로 전환 (재입장 시 퇴장만 가능).
   - 수면 심도 회복 (회복량 미정 — 밸런스 조정 예정)
   - 체력 회복 (정액 회복 vs 현재 HP 비율(%) 회복 중 방식 미정, 수치도 미정)
   - 단련: 최대 체력 증가 (증가량 미정 — 밸런스 조정 예정)
2. **일반 전투방 (CombatNode)**: 일반 몬스터와 조우. 승리 시 재화('무의식의 잔재') 획득.
3. **엘리트 전투방 (EliteNode)**: 악몽의 심연. 강력한 중간 보스 조우. 승리 시 다음 층 열쇠인 '기억의 파편' 획득 + Max HP +20 성장 + 현재 HP 완충.
4. **상인의 방 (MerchantNode)**: 재화를 소모해 영구 성장 아이템/조합 재료를 구매하는 상점. (상세는 8절)
5. **잠긴 문 (LockedNode)**: 다음 층으로 가는 출구. '기억의 파편' 소지 여부 확인 후 통과.

## 5. 맵 테마 (5단계 감정의 층)

주인공의 심리 상태를 반영한 5가지 감정 테마로 구성되며, 층마다 차별화된 시스템적 페널티와 분위기를 가짐.

| 층(Round) | 감정 테마 | 분위기 및 시스템 특징 |
|---|---|---|
| Map 1 | 향수 (Nostalgia) | 거짓된 평온. 난이도가 낮고 휴식처가 잦음. |
| Map 2 | 우울 (Melancholy) | 무기력. 수면 심도 소모량 증가, 둔화 페이즈 존재. |
| Map 3 | 분노 (Anger) | 공격성. 적의 공격력 상승, 빠른 전투 템포, 휴식처 희귀. |
| Map 4 | 공포 (Fear) | 시야 제한. 미지의 방 정찰 비용 대폭 증가. |
| Map 5 | 공허 (Void) | 진실. 최종 목적지(보스전), 직선형 구조, 최고 난이도. |

## 6. 전투 (Combat) 시스템

- 진행 방식: 1:1 교대 턴제 전투 (속도 스탯 배제, 플레이어와 적이 한 턴씩 번갈아 행동).
- 플레이어 행동 옵션:
  - 공격: 장착 중인 무기의 성능으로 데미지 부여.
  - 도구 사용: 주머니에 있는 재료를 소모해 즉발 효과 발휘.
  - 방어: 해당 턴에 받는 피해 감소.

## 7. 코어 특색: 꿈조합 (Dream Synthesis) 시스템

- 개념: 보잘것없는 일상 도구들을 결합하여 상식을 벗어난 강력한 '꿈무기'로 재창조하는 시스템.
- 제약 조건: 전투 중(CombatState)에는 조합 불가. 오직 탐색 중(ExplorationState)일 때만 인벤토리 메뉴를 통해 실행 가능.
- 로직: 주머니에 있는 2개의 재료(Base 형태 1개 + Modifier 속성 1개)를 소모하여, 두 사물의 특성이 결합된 새로운 무기 1개를 생성.
- 기술적 구현 제약:
  - `enum class`와 비트마스크(Bitmask) 연산(`|`, `&`)을 활용해 아이템 속성을 제어 (하드코딩 방지).
  - 팩토리 패턴을 적용하여, 조합 대상 객체의 포인터를 `std::move`로 전달받고 새 무기 객체 반환 시 기존 객체의 메모리를 해제할 것.

## 8. 상점 (Merchant) 시스템

- 재화: 일반 및 엘리트 전투 승리 시 획득하는 '무의식의 잔재'.
- 판매 품목:
  - 심연의 물약: 구매 즉시 Max HP +10 및 현재 HP 회복 (인벤토리를 거치지 않고 즉시 적용).
  - 무작위 조합 재료: 현재 맵 테마에 맞는 Base 혹은 Modifier 아이템 (인벤토리 슬롯 필요).
- 규칙: 구매 횟수 제한 없음. 단, 재화 부족 또는 주머니가 가득 찬 경우(재료 구매 시) 구매 제한. 상점 퇴장 시 해당 노드는 '빈 방'으로 전환.
