## 1. 프로젝트 개요

- 프로젝트명: Place of My Dream (POMD)
- 장르: 턴제 로그라이크 (노드 탐색형)
- 개발 환경: C++, Windows Console API (화면 깜빡임 방지용 커서 제어 활용)
- 개발 기간: 30일 (여름 집중 포트폴리오 프로젝트)
- 핵심 내러티브: 플레이어는 자각몽 속 무의식의 세계를 탐험하며 잊혀진 '기억의 파편'을 찾아 더 깊은 심연으로 나아간다. 수면 심도가 다하여 꿈에서 깨어나기 전에 최종 목적지에 도달해야 한다.

## 2. 개발 및 설계 목표 (포트폴리오 어필 포인트)

- 메모리 최적화: `std::vector`의 capacity 제어 및 연속된 메모리 할당(Object Pool)을 통한 캐시 적중률(Data Locality) 향상.
- 모던 C++ 활용: `std::move`를 활용한 R-value 소유권 이전과 팩토리 패턴을 결합하여, 메모리 누수(Leak) 없는 생명 주기 제어.
- 데이터 구조 최적화: 비트마스크(Bitmask) 연산을 통한 상태/속성 제어 및 구조체 메모리 패딩(Padding)/정렬(Alignment) 최적화.
- (기존) 객체지향 설계: 다형성을 활용한 유연한 노드(방) 및 엔티티(몬스터, 플레이어) 클래스 구조 설계.
- (기존) 자료구조 활용: 노드 간의 연결 상태를 구현하기 위한 그래프(Graph) 활용.
- (기존) 상태 관리: 턴제 전투 흐름 및 맵 탐색 씬(Scene) 전환의 State Machine 기반 제어.
- (기존) 데이터 캡슐화: '수면 심도', 'HP' 등 핵심 데이터를 캡슐화하고 이벤트에 유기적으로 반응하는 구조(옵저버 패턴) 구현.

## 3. 핵심 자원 및 플레이어 스탯

- 수면 심도 (Sleep Depth): 게임의 코어 자원. 맵 이동, 정찰(Scout), 특수 행동 시 소모되며 0이 되면 게임 오버(Run 실패).
- HP (체력): 0이 되면 게임 오버.
- ATK (공격력) / DEF (방어력): 전투 시 데미지 계산을 위한 기본 스탯. 턴 진행은 속도(Speed) 계산 없이 플레이어와 적이 1:1로 교대하는 심플한 구조를 채택.
- 인벤토리: 장착 무기 슬롯 1개 + 주머니 슬롯 3개.

## 4. 맵 및 탐색 시스템 (Map & Exploration)

- 맵 구조: 각 층(Map)은 노드(Node)들이 유기적으로 연결된 그래프(Graph) 구조이며, 뒤로가기가 가능한 탐색형 맵.
- 정보 해금 (Fog of War):
  - 초기에는 방의 내용물이 `[ ? ]` 상태로 표기됨.
  - 이동(Move): 수면 심도를 소량 소모하여 리스크를 안고 진입.
  - 정찰(Scout): 수면 심도를 대량 소모하여 방의 정보를 해금(안전 확보).

### 노드(방)의 종류

1. 휴식처 (RestNode): 수면 심도/HP 1회성 회복 후 빈 방으로 전환.
2. 일반 전투방 (CombatNode): 일반 몬스터 전투 및 보상 획득.
3. 엘리트 전투방 (EliteNode): 악몽의 심연. 숨겨진 중간 보스전이며, 승리 시 다음 층으로 가는 열쇠인 '기억의 파편' 확정 드롭.
4. 상인의 방 (MerchantNode): 획득한 재화를 소모하여 스탯 증가(최대 HP 등) 혹은 소비형 아이템 구매.
5. 잠긴 문 (LockedNode): 다음 층으로 가는 출구. 기억의 파편 소지 여부 체크.

## 5. 맵 테마 (5단계 감정의 층)

주인공의 심리 상태를 반영한 5가지 감정 테마로 구성되며, 층마다 차별화된 시스템적 페널티와 분위기를 가짐.

| 층(Round) | 감정 테마 | 분위기 및 시스템 특징 |
|---|---|---|
| Map 1 | 향수 (Nostalgia) | 거짓된 평온. 난이도가 낮고 휴식처가 잦음. |
| Map 2 | 우울 (Melancholy) | 무기력. 수면 심도 소모 증가 및 둔화 디버프 등장. |
| Map 3 | 분노 (Anger) | 공격성. 적의 공격력이 높고 전투 템포가 빠르며 휴식처 희귀. |
| Map 4 | 공포 (Fear) | 시야 제한. 미지의 방 `[ ? ]` 정찰 시 수면 심도 소모량 대폭 증가. |
| Map 5 | 공허 (Void) | 진실. 방의 개수가 적고 직선적이지만 적이 가장 강력함 (보스전). |

## 6. 코어 특색: 꿈조합 (Dream Synthesis) 시스템

- 개념: 자각몽 테마를 활용하여, 보잘것없는 일상 도구 2개를 결합해 강력하고 기괴한 '꿈무기'로 재창조.
- 제약 조건: 전투 중(CombatState)에는 조합 불가. 오직 탐색 중(ExplorationState)일 때만 인벤토리 메뉴를 열어 조합 가능.
- 기술적 구현 제약:
  - `enum class`와 비트마스크(Bitmask) 연산(`|`, `&`)을 활용해 아이템 속성을 제어 (하드코딩 방지).
  - 팩토리 패턴을 적용하여, 조합 대상 객체의 포인터를 `std::move`로 전달받고 새 무기 객체 반환 시 기존 객체의 메모리를 해제할 것.
