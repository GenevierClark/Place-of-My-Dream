## 1. 프로젝트 개요

- 프로젝트명: Place of My Dream (POMD)
- 장르: JRPG 스타일 턴제 어드벤처 (노드 탐색형)
- 플랫폼: C++ 콘솔 환경 (Windows Console API 기반 렌더링)
- 개발 기간: 30일 (여름 집중 포트폴리오 프로젝트)
- 핵심 내러티브: 플레이어는 자각몽 속 무의식의 세계를 탐험하며 잊혀진 '기억의 파편'을 찾아 더 깊은 심연으로 나아간다.

## 2. 개발 및 설계 목표 (포트폴리오 어필 포인트)

- 메모리 최적화: `std::vector`의 capacity 제어 및 연속된 메모리 할당(Object Pool)을 통한 캐시 적중률(Data Locality) 향상.
- 모던 C++ 활용: `std::move`를 활용한 R-value 소유권 이전과 팩토리 패턴을 결합하여, 메모리 누수(Leak) 없는 생명 주기 제어.
- 데이터 구조 최적화: 비트마스크(Bitmask) 연산을 통한 상태/속성 제어 및 구조체 메모리 패딩(Padding)/정렬(Alignment) 최적화.
- 객체지향 설계: 다형성을 활용한 유연한 노드(방) 및 엔티티(몬스터, 플레이어) 클래스 구조 설계.
- 자료구조 활용: 노드 간의 연결 상태를 구현하기 위한 그래프(Graph) 활용.
- 상태 관리: 턴제 전투 흐름 및 맵 탐색 씬(Scene) 전환의 State Machine 기반 제어.
- 데이터 캡슐화: 핵심 데이터를 캡슐화하고 이벤트에 유기적으로 반응하는 구조(옵저버 패턴) 구현.

## 3. 플레이어 캐릭터 시스템

### 3.1. 기본 스탯 및 자원

- 수면 심도 (Sleep Depth): **0~100 사이의 텐션(Tension) 게이지** (초기 시작값 50). 양 끝(0 또는 100) 모두 특수 상태를 유발함 — 상세는 4절 참고.
- 체력 (HP): 전투 피격 시 감소. 휴식처의 '단련' 선택지나 엘리트 몬스터 처치로 최대 체력(Max HP)을 영구 성장 가능.
- 공격력(ATK) / 방어력(DEF): **플레이어 맨몸 기본 ATK는 1, DEF는 0으로 고정.** 스탯 성장은 오직 장착 중인 무기를 통해서만 이루어짐 (레벨업 등 별도 성장 없음).

### 3.2. 인벤토리 구조

- 장착 무기 슬롯: 1개 (현재 전투에서 사용하는 주력 무기)
- 주머니 슬롯: 3개 고정 (탐색 중 획득한 재료 보관)
- 예외 처리: 주머니가 3칸 모두 찬 상태에서는 추가 재료 획득 제한.

## 4. 수면 심도(텐션 게이지) 및 사망/부활 시스템

수면 심도는 0~100 사이를 오가는 게이지이며, 양 끝에 도달하면 서로 다른 결과가 발생함. HP가 0이 되는 경우도 별도로 처리됨.

- **수면 심도 감소** (0 방향): 맵 이동, 정찰 기능 사용, 몬스터의 특정 패턴 피격 시.
- **수면 심도 증가** (100 방향): 휴식처(RestNode)에서 '수면 심도 회복' 선택 시.

### 조건 A — 수면 심도가 0이 된 경우 (강제 기상)

- 결과: 즉시 꿈에서 깨어나며, 해당 층(Map) 탐색을 완전히 실패한 것으로 간주.
- 부활 지점: 해당 층의 처음(입구)부터 다시 진행.
- 패널티: **해당 층에서 획득한 모든 아이템이 삭제됨.** (이전 층까지의 진행 상황 및 성장치는 유지)

### 조건 B — 수면 심도가 100이 된 경우 (과수면/심연 진입)

- 결과: 무의식의 억압이 풀린 **하드모드(Hard Mode)**에 돌입.
- 게이지 잠금: 수면 심도가 100으로 고정, 이동/피격으로도 더 이상 내려가지 않음.
- 적 전역 강화 (Global Buff): 맵의 모든 적이 강화 상태로 변경 (스탯 강화, 타입 변경, 특수 스킬 등 — 상세 TBD).
- 해제 조건: 특수 아이템 사용, 또는 해당 층 보스 처치 후 다음 층 진입 시 상태 해제 및 심도 원복.

### 조건 C — 체력(HP)이 0이 된 경우 (전투 불능)

- 결과: 완전히 깨어나지 않고 꿈의 얕은 곳으로 튕겨 나감.
- 부활 지점: **마지막으로 휴식을 취했던 휴식처(RestNode)**에서 재시작 (층 입구가 아님).
- 패널티: 부활 시 수면 심도가 일정량 감소 (구체 수치 TBD).

## 5. 맵 및 탐색 시스템 (Map & Exploration)

- 맵 구조: **고정 구조(Fixed Map)** — 모든 층의 전체 노드 개수, 노드 종류, 노드 간 연결(Edge)은 기획자가 의도한 고정 데이터대로 배치됨. **절차적/랜덤 생성은 배제.**
- 정보 해금 (Fog of War):
  - 초기 진입 시 인접한 방의 존재는 확인 가능하나, 내부 정보는 `[ ? ]`로 가려짐.
  - 이동(Move): 소량의 수면 심도를 소모하며 인접 방으로 진입 (리스크 감수).
  - 정찰(Scout): 대량의 수면 심도를 소모하여 인접 방의 상세 정보를 미리 해금 (안전 확보).

### 노드(방)의 종류

1. **휴식처 (RestNode)**: 진입 시 아래 세 선택지 중 **단 하나만** 선택 가능. 선택 후 빈 방으로 전환 (재입장 시 퇴장만 가능).
   - 수면 심도 회복 (회복량 미정 — 밸런스 조정 예정)
   - 체력 회복 (정액 회복 vs 현재 HP 비율(%) 회복 중 방식 미정, 수치도 미정)
   - 단련: 최대 체력 증가 (증가량 미정 — 밸런스 조정 예정)
2. **일반 전투방 (CombatNode)**: 일반 몬스터와 조우. 승리 시 재화('꿈의 파편') 획득.
3. **엘리트 전투방 (EliteNode)**: 층의 중간 보스 조우. 승리 보상 **미정 (TBD)**.
4. **상인의 방 (MerchantNode)**: 재화를 소모해 영구 성장 아이템/조합 재료를 구매하는 상점. (상세는 9절)
5. **이벤트 방 (EventNode)**: 해당 층의 서사(주인공의 과거, 기억 등)를 전달하는 특수 노드. 상호작용 완료 시 해당 층의 `[스토리 완료 플래그]` 활성화.
6. **잠긴 문 (LockedNode)**: 다음 층으로 가는 출구. **아래 두 조건을 모두 만족해야만** 통과 가능.
   - 조건 A: '기억의 파편' 소지.
   - 조건 B: 해당 층의 `[스토리 완료 플래그]` 활성화 (EventNode 상호작용 완료).

## 6. 맵 테마 (5단계 감정의 층)

주인공의 심리 상태를 반영한 5가지 감정 테마로 구성되며, 층마다 차별화된 시스템적 페널티와 분위기를 가짐.

| 층(Round) | 감정 테마 | 분위기 및 시스템 특징 |
|---|---|---|
| Map 1 | 향수 (Nostalgia) | 거짓된 평온. 난이도가 낮고 휴식처가 잦음. |
| Map 2 | 우울 (Melancholy) | 무기력. 수면 심도 소모량 증가, 둔화 페이즈 존재. |
| Map 3 | 분노 (Anger) | 공격성. 적의 공격력 상승, 빠른 전투 템포, 휴식처 희귀. |
| Map 4 | 공포 (Fear) | 시야 제한. 미지의 방 정찰 비용 대폭 증가. |
| Map 5 | 공허 (Void) | 진실. 최종 목적지(보스전), 직선형 구조, 최고 난이도. |

## 7. 전투 및 몬스터 AI 시스템

### 7.1. 전투 기본 흐름

- 진행 방식: 1:1 교대 턴제 전투 (속도 스탯 배제, 플레이어와 적이 한 턴씩 번갈아 행동).
- **턴 진행 3단계 (Phase)**: `[1단계: 상태이상/디버프 정산]` → `[2단계: 행동 결정 및 실행]` → `[3단계: 턴 종료]`

### 7.2. 플레이어 턴 커맨드 (Phase 2, V4.2 구체화)

플레이어는 자신의 턴에 아래 4가지 중 하나를 선택.

1. **기본 공격 (Base Attack)**: 맨몸이거나 무기 장착 상태일 때 항상 사용 가능. 무기 Base의 ATK 수치만큼 **`[무속성]`** 물리 데미지. 수면 심도 소모 없음 (안정적이지만 속성 약점을 못 찌름).
2. **특수 스킬 (Attribute Skill)**: 꿈조합으로 Modifier(속성)가 부여된 무기 장착 시에만 활성화. Modifier의 고유 스킬 발동 — 상성이 적용되는 `[속성]` 데미지 + 특수 효과. **코스트(불안정한 꿈)**: 스킬마다 정해진 범위로 수면 심도가 무작위로 변동 (방향은 8.2절 참고).
3. **방어 (Defend)**: 해당 턴에 받는 데미지 반감.
4. **도구 (Item)**: 주머니 슬롯의 소모품 사용.

> ⚠️ 2번(특수 스킬)과 4번(도구)은 각각 무기/꿈조합 시스템과 인벤토리 시스템이 먼저 구현되어야 실제로 동작 가능. 지금 구현 가능한 건 1번(기본 공격)과 3번(방어)뿐.

### 7.3. 몬스터 행동 규약 (AI Priority)

모든 몬스터는 자신의 턴(Phase 2)이 돌아오면 아래 레이어를 순차적으로 검사하여 행동을 결정함.

1. **1순위 [조건부 특수 행동]**: 특정 조건(자신의 HP 30% 이하, 약점 피격 등)이 만족되면 2순위 사이클을 강제로 끊고(Interrupt) 특수 패턴을 최우선 실행.
2. **2순위 [고정 사이클 행동]**: 1순위 조건이 없을 경우, 몬스터 고유의 정해진 턴 테이블(예: 1턴 평타 → 2턴 방어 → 3턴 강공격)을 반복 실행.

몬스터마다 고유한 HP/ATK/DEF, 드롭 재화량, 그리고 위 규약에 따른 개별 패턴을 가짐 — 상세는 12절 참고.

## 8. 감정 속성(Attribute) 시스템

### 8.1. 속성 종류 및 상성 (V4.2에서 확정)

- 속성 종류: `[자각 (Lucid)]`, `[몽환 (Illusion)]`, `[망각 (Oblivion)]` (+ `[과수면 (Hypersomnia)]`, 8.3절 참고)
- 상성 (삼각 구도, 순환형):
  - `[자각]` → `[몽환]`: **2배** 약점 데미지
  - `[몽환]` → `[망각]`: **2배** 약점 데미지
  - `[망각]` → `[자각]`: **2배** 약점 데미지
  - 역상성(위와 반대 방향으로 공격) 시: 0.5배로 반감. **단, 최소 데미지 1은 항상 보장.**
- 속성 부여 룰: 무기에 Modifier(꿈조합 재료)를 결합해야 속성이 부여됨 — 상세는 9절 참고.

### 8.3. 과수면 (Hypersomnia) — 4번째 특수 속성

- 일반적인 감정 속성(자각/몽환/망각)과는 별개로, **수면 심도가 100에 도달했을 때(4절 조건 B, 하드모드)** 진입하는 특수 상태.
- 기본 3속성의 상성 삼각 구도와는 무관하게, 추후 별도의 특수 능력/효과를 부여하도록 설계 예정 (상세 TBD).

### 8.2. 속성별 플레이어 스킬 코스트 방향성 (신규)

무기에 부여된 속성에 따라, "특수 스킬"(7.2절 커맨드 2번) 사용 시 수면 심도가 변동하는 방향과 폭이 다름.

| 속성 | 효과 | 수면 심도 변동 | 유발 리스크 |
|---|---|---|---|
| `[자각 (Lucid)]` | 현실로 당기는 힘 | 0 방향으로 무작위 감소 (예: -5 ~ -15) | 강제 기상(조건 A) 리스크 |
| `[망각 (Oblivion)]` | 심연으로 끄는 힘 | 100 방향으로 무작위 증가 (예: +5 ~ +15) | 과수면 진입(조건 B) 리스크 |
| `[몽환 (Illusion)]` | 비틀린 환상 | 증감 방향 자체가 무작위 (예: -10 ~ +10) | 극도의 변수/예측 불가 |

## 9. 코어 특색: 꿈조합 (Dream Synthesis) 시스템

- 개념: 보잘것없는 일상 도구들을 결합하여 상식을 벗어난 강력한 '꿈무기'로 재창조하는 시스템.
- 제약 조건: 전투 중(CombatState)에는 조합 불가. 오직 탐색 중(ExplorationState)일 때만 인벤토리 메뉴를 통해 실행 가능.
- 로직: 주머니에 있는 2개의 재료(Base 형태 1개 + Modifier 속성 1개)를 소모하여, 두 사물의 특성이 결합된 새로운 무기 1개를 생성.
- **역할 분담 (V4.2 명확화)**:
  - `Base`(뼈대): 무기의 기본 물리 ATK 수치를 결정 (7.2절 "기본 공격"에 사용됨).
  - `Modifier`(속성 부여): 무기의 감정 속성과, 특수 스킬 로직(변동 수면 심도 코스트 포함)을 결정 (7.2절 "특수 스킬"에 사용됨).
- 기술적 구현 제약:
  - `enum class`와 비트마스크(Bitmask) 연산(`|`, `&`)을 활용해 아이템 속성을 제어 (하드코딩 방지).
  - 팩토리 패턴을 적용하여, 조합 대상 객체의 포인터를 `std::move`로 전달받고 새 무기 객체 반환 시 기존 객체의 메모리를 해제할 것.

## 10. 상점 (Merchant) 시스템

- 재화: 전투 승리 보상 '꿈의 파편'.
- 판매 품목:
  - 심연의 물약: 구매 즉시 Max HP 증가 및 현재 HP 회복 (수치 미정, 인벤토리를 거치지 않고 즉시 적용).
  - 무작위 조합 재료: 해당 층 테마에 맞는 Base 혹은 Modifier 아이템 (인벤토리 슬롯 필요).
- 규칙: 구매 횟수 제한 없음. 단, 재화 부족 또는 주머니가 가득 찬 경우(재료 구매 시) 구매 제한. 상점 퇴장 시 해당 노드는 '빈 방'으로 전환.
